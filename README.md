# JunctionX Turku TYKS Challenge

A web application developed for the JunctionX Turku TYKS Challenge.

## Development

You need Node.js and npm installed. We recommend using nvm:

[Install Node.js with nvm](https://github.com/nvm-sh/nvm#installing-and-updating)

### Setup

```sh
git clone <repository-url>
cd JunctionX-Turku-TYKS-Challenge
npm install
npm run dev
```

## Built With

- TanStack Start
- TypeScript
- React
- Tailwind CSS
